# Jessica Gunsallus — Product Portfolio

Static recruiter-facing portfolio site for Jessica Gunsallus, Product Manager / Technical Product Manager.

## Live site

The portfolio is published at:

`https://jguns222.github.io`

## Portfolio structure

- `index.html` — portfolio content and case studies
- `styles.css` — responsive visual design
- `script.js` — resume downloads, footer year, and accessible navigation state

## Notes

- Professional and academic case studies are explicitly labeled.
- Featured projects include code-native product-screen illustrations for SurveyPocket and DietAlly.
- WGU academic work and evaluator feedback are presented separately from professional outcomes.
- Official WGU Excellence Award certificates are available as correctly labeled PDFs in `certificates/`.
- Full and one-page recruiter resume PDFs are versioned in `resumes/` for direct, sign-in-free downloads.
- No home address, phone number, or sensitive personal information is included.
- Contact links use email, LinkedIn, and GitHub.
- The site is responsive and has no build process or framework dependency.
